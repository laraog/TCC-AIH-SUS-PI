# TCC-AIH-SUS-PI
Notebooks de análise do valor médio das internações hospitalares no Piauí (2018–2025)

O processamento dos dados, a análise exploratória, a modelagem e a interpretação dos resultados foram realizados em notebooks Jupyter, executados no ambiente Google Colab, com Python 3.13.18. As bibliotecas utilizadas e suas respectivas versões estão especificadas no arquivo requirements.txt.
